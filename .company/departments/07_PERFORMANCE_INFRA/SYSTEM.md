# System & Infra Performance: 07_PERFORMANCE_INFRA

## Performance Targets
1. **Memory Bar & Sector Grid Render**: < 16ms (60 FPS) rendering latency even with 4,096 sectors.
2. **Binary Pack Time**: < 100ms for 8 MB binary generation with 0xFF padding.
3. **CRC32 & SHA-256 Calculation**: < 50ms for 2 MB image.
4. **Bundle Size**: < 200 KB gzipped.
